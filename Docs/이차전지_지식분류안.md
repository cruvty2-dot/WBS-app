# 이차전지 지식 분류안

> 2026-10-02 | 제안안 | 큰 축: 설계 / 공정

소재·물성·반응을 찾는 **지식 분류**와 프로젝트 산출물을 나누는 **WBS(작업 분류 체계)**를 별도로 연결한다. 이 문서의 계층은 앱의 탐색 구조다. 국제표준이 정한 이차전지 분류표라는 의미는 아니다.

## 분류 원칙

1. 활물질·바인더·도전재·전해질·분리막·집전체는 기능별로 나란히 둔다. 양극재와 음극재는 활물질 아래로 둔다.
2. Li 같은 원소는 공통 문서 하나를 두고 양극·음극·전해질·공정에서 관련 링크로 연결한다. Li가 특정 양극재의 하위 종류라는 잘못된 포함 관계를 만들지 않는다.
3. 설명 문서에는 대표 분류 하나와 관련 분류 목록을 둔다. 파일 복제 대신 ID와 링크를 사용한다.
4. 측정법의 원리는 설계의 평가·분석에, 현장 품질 적용은 공정의 품질·데이터에 연결한다.
5. 이 JSON은 분류안과 문서 링크다. 말단 항목 전부의 상세 지식을 작성한 상태는 아니며, 연결 문서는 현재 확보한 주제 참고자료다.

## Li를 찾는 예

대표 위치는 `이차전지 → 설계 → 소재·재료 → 소재 특성·전공 기초 → 원소·이온 → Li: 원소·Li⁺·금속 음극`이다. `NCM → 관련 원소 → Li`, `금속 음극 → 리튬 금속 → Li`, `공정 → 소재 제조 → 리튬화 → Li`는 같은 상세 문서를 참조한다. 앱 화면에서는 관련 재료·공정 링크를 함께 보여주도록 설계한다.
