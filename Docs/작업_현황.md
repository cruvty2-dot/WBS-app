## 앞으로의 PDF 제공

새 PDF는 별도 요청 시 GitHub 최신 내용을 확인해 가장 아래 개별 항목만 만들고 이 채팅에서 공부용으로 제공한다. 상위 합본을 만들지 않으며 GitHub에 PDF를 자동 업로드하지 않는다. Markdown 수정과 PDF 제작을 분리한다. 기존 PDF는 이전 보존본이며 최신 상태는 Markdown과 학습 데이터를 따른다.
