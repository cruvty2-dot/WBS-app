# 작업 현황

> 2026-10-03

## 완료

- Battery Study 이름과 설계/공정 두 축의 WBS 분류를 유지한다. 전체 195개 항목의 번호·이름·PDF 연결이 일치한다.
- 1.1 소재·재료의 93개 항목을 선수학습 → 기초지식 → 핵심 원리·예제·조건 → 열화와 분석·확인 문제 → 참고근거 → 이후 연계학습 형식으로 정리했다.
- Li·Ni·Mn의 검토 내용을 반영하고, 나머지 90개 항목을 원소·기초 이론·활물질·바인더·도전재·전해질·분리막·집전체의 범위에 맞춰 확장했다.
- NCM·LFP·LMFP·흑연·하드카본·Si에는 주요 개념을 더 깊게 설명하는 절을 추가했다. Si/C 복합재와 SiC 화합물, 형식 산화수와 부분 전하, 전위와 셀 전압, 활물질과 셀 질량 기준을 구별한다.
- 최근 연구 사례의 확인일·근거·적용 조건을 남겼다. NCM·LMFP·Na 하드카본 등을 현재 사례로 사용하되 연구 흐름에 따라 갱신한다.
- 이번 작업에서 직접 제작한 계산·개념 그림 10종과 기존 Li·Ni·Mn 그림을 사용한다. 그림의 모형 값과 이론 상한·실험 결과를 구별한다.
- 가장 아래 PDF는 해당 항목만, 상위 PDF는 본 항목과 모든 하위 단계의 내용을 포함한다. 책갈피·합본 페이지 번호·포함 범위 목록을 함께 생성한다.
- 상세문서는 총98개(소재93개와 기존 원료 공정5개)다. 나머지97개는 학습 시작용 핵심 요약이다. 학습 완료 기록이 없으므로 상태는 미학습이다.
- 본문 원본은 Data/wbs-learning.json으로 관리한다. 해당 PDF·상위 합본·읽기용 Markdown·README를 같은 경로에 갱신하고 이전 내용은 Git 이력으로 남긴다.
- 원본의 102개 자료 페이지와 이전 주제별 자료는 별도 참고자료로 보존한다.
