# 저장 구조와 기록 규칙

> 2026-10-02 | 앱 자체 설계안

## 파일별 역할

| 경로 | 역할 |
| --- | --- |
| Data/taxonomy.json | 설계·공정 분류 ID·부모·관련 링크 |
| Data/wbs-learning.json | 항목별 학습 상태·핵심·선수학습·본문·근거의 내용 원본 |
| Data/wbs-pdf-manifest.json | PDF 범위·포함 항목·실제 쪽수 |
| Data/topic-manifest.json | 주제·원본 쪽수·PDF·Markdown·보완 설명 |
| Data/source-page-map.json | 분리 PDF 쪽수와 원본 파일·쪽수의 대응 |
| Knowledge/topics/ | 주제별 보완 설명·자료 링크 |
| Knowledge/items/ | 항목별 상세 설명의 읽기용 Markdown |
| Knowledge/materials/ | 기존 경로에서 최신 항목 문서로 안내 |
| Knowledge/ideas/ | 아이디어·질문과 검증 작업 |
| References/wbs/ | WBS 번호·항목명에 맞춘 단일 항목 및 상위 합본 PDF |
| References/topics/ | 원문 표·그림 확인용 이전 주제별 참고 PDF |
| Templates/ | 향후 작업 요청·분석 기록의 빈 양식 |
| Projects/ | 프로젝트 WBS 예시·향후 실제 프로젝트 |
| Tools/ | PDF 제작·파일 연결 검증 스크립트 |

JSON은 관계와 메타데이터(자료를 설명하는 정보), Markdown은 설명, CSV는 표 데이터, PDF는 그래프·표와 학습용 문서에 사용한다. 이 조합은 앱의 선택이다. 관련 표준은 [표준 지침](이차전지_WBS_표준_지침.md)을 참고한다.

## 분석 한 건의 기록

`id`, `request_id`, `title`, `primary_category_id`, `related_category_ids`, `wbs_task_ids`, `input_files`, `code_files`, `result_files`, `created_at`, `author`, `review_status`, `measurements`, `assumptions`, `limitations`, `standard_refs`, `environment`를 사용한다. 시료·로트·측정조건도 필요에 따라 연결한다.

| 필드 | 기준 |
| --- | --- |
| 분류 ID | taxonomy에 존재하는 ID; 제목·경로 변경과 별개로 유지 |
| wbs_task_ids | 프로젝트와 산출물이 정의된 실제 작업에만 연결 |
| 파일 경로 | 저장소 기준 상대경로; 존재하는 파일만 기록 |
| 시간 | 시간대가 포함된 ISO 8601 표기 |
| 수치 | 값·단위·기준 질량/면적·측정조건을 같이 기록 |
| 원본 | 변경하지 않은 입력과 SHA-256 해시로 구별 |
| 모델 | 실측·계산·예측 구분; 가정·검증 자료를 연결 |
| 표준 | 번호·판본·적용 대상·확인일·적용 판단; 번호만으로 적합성을 주장하지 않음 |

검토 상태는 `draft`, `needs_classification`, `pending_review`, `approved`, `rejected`, `superseded`를 사용한다. 원문 참고자료는 `reference`로 별도 표시하고, 최신 규격으로 사실검증 완료된 설명처럼 보여주지 않는다.

## 상세 문서 작성 양식

선수학습 → 먼저 알아둘 기초 → 해당 항목의 핵심 내용 → 확인 질문 → 참고 근거 → 이후 연계학습 순서다. 선수학습과 이후 연계학습은 WBS 번호·항목명으로 간단히 적는다. 원소·화합물·전극·셀의 물성을 구분한다. 개편 이력은 학습 본문 대신 Git 변경 이력과 작업 현황에 남긴다. [학습문서 양식](../Templates/학습문서.md)을 따른다.

## 공개 범위

현재 저장소는 공개다. 이번 자료는 사용자가 업로드를 요청한 학습자료다. 향후 연구실 실험 데이터·장비 조건·비공개 문헌은 공개 저장소에 자동 업로드하는 대상으로 삼지 않고 공개 학습 템플릿과 별도로 관리한다. 파일명만 바꾸는 것은 익명화나 기밀 제거가 아니다.

## PDF 개정 방식

`Data/wbs-learning.json`을 한 번 수정한 뒤 항목별 PDF와 모든 상위 합본을 함께 생성한다. `2 공정`에는 `2.1~2.7`뿐 아니라 그 아래 모든 단계가 포함된다. 같은 규칙을 전체 분류에 재귀적으로 적용한다. PDF 책갈피·실제 쪽수·포함 항목을 검증하고 README를 갱신한다.

전용 상세내용이 없는 항목은 미학습·핵심 요약으로 표시한다. 핵심 요약 PDF를 실제로 만들었을 때만 해당 파일을 연결하며, 공통 PDF로 대체하지 않는다. 아직 학습하지 않은 상세문서도 학습 상태는 미학습으로 유지한다.

이전 원문 재배치 자료는 별도 참고자료로 보존한다. 필요한 표·그림과 설명은 해당 항목을 다듬을 때 범위·조건·근거를 검토해 포함한다. 현재 WBS PDF는 원문 페이지를 그대로 덧붙인 파일이 아니다.
