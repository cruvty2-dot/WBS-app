# 학습문서 구성과 소분류 기준

한 문서에서 하나의 학습 항목을 충분히 설명하고, 원인·결과·증거를 연결한다. WBS 위치와 실제 선수학습 순서는 별도로 관리한다. 가장 작은 항목부터 하나씩 작성하고, 기준도 실제 문서를 보면서 다듬는다.

## 1. 다섯 구역의 역할

| 구역 | 포함할 내용 | 선정 기준 |
| --- | --- | --- |
| 선수학습 | 필요한 기존 항목의 WBS 번호·이름 | 해당 개념을 모르면 본문의 핵심 설명을 따라가기 어려운가? |
| 기초지식 | 용어·기호·단위·물질의 존재 형태·계산 가정 | 이 문서에서 몇 문장으로 설명하고 출발할 수 있는가? |
| 핵심내용 | 역할·이론·작동 과정·조건·예제·열화와 분석·확인 문제 | 이 항목을 읽은 뒤 무엇을 설명하거나 판단할 수 있는가? |
| 참고근거 | 공식 자료·원 논문·계산·그림의 출처와 적용 범위 | 어떤 주장과 결과를 뒷받침하며 어디까지 적용되는가? |
| 연계학습 | 이해한 뒤 이어갈 항목의 WBS 번호·이름 | 지금 내용을 사용해 더 깊게 이해할 대상인가? |

실제 선수학습·연계학습 목록에는 번호와 항목명만 쓴다. 연결문서가 아직 요약 수준이어도 완료를 요구하지 않으며, 필요한 개념을 이해했는지를 기준으로 읽는다. 학습 완료 상태는 사용자가 공부한 뒤 바꾼다.

## 2. 핵심내용의 기본 순서

1. **역할과 기본 이론**: 정의·쓰임·구조·결합·반응.
2. **작동 원리**: 무엇이 변하고 어디로 이동하며 왜 그렇게 되는지.
3. **예제와 주요 특성**: 직접 계산·그림·비교·측정 결과를 가정과 단위와 함께 제시.
4. **특성을 좌우하는 조건**: 조성·구조·환경·시험 조건과 결과의 관계.
5. **열화와 분석·해석**: 현상별 원인·성능 영향·확인 증거·판단 한계.
6. **확인 문제와 해설**: 구분·인과관계·계산·증거 해석을 직접 설명.

절은 주제에 맞춰 선택한다. 원소·기초 이론·분석법·공정마다 필요한 설명이 다르므로 분량과 절 수를 동일하게 맞추지 않는다. 원소 문서의 소재 사례는 원소의 역할을 설명하는 범위에서 사용한다. 소재 전체의 설계·합성·평가는 해당 소재 문서에서 다룬다.

열화는 “현상 → 발생 과정 → 성능 영향 → 분석법과 관찰 → 해석 한계”를 한 묶음으로 쓴다. 분석법은 조성·구조·전자상태·표면·형태·전기화학 중 무엇을 측정하는지 명시한다. 관찰한 사실, 가능한 설명, 추가 확인을 구별한다. 처음부터 있던 결함과 사용 중에 진행된 열화도 구별한다.

## 3. NCM에서 선정하는 예

| 후보 | 현재 WBS 항목 | 배치 판단 |
| --- | --- | --- |
| Li와 Ni·Co·Mn의 존재 형태·역할 | 1.1.1.1.1~1.1.1.1.4 | NCM의 조성과 반응을 읽는 선수학습 후보. 각 원소의 모든 세부 내용을 먼저 외울 필요는 없다. |
| 층상 구조 | 1.1.1.2.1 층상 구조 | Li층·전이금속층·산소 골격을 이해하는 선수학습 후보. |
| 산화수·산화환원 | 1.1.1.3.1 화학결합·산화수 / 1.1.1.3.3 산화·환원과 전위 | 반응식과 전하량을 설명하는 선수학습 후보. |
| c축 수축을 포함한 비등방성 격자 변화 | 1.1.1.2.5 상전이·응력·균열 | NCM에서 발생하는 현상은 NCM 본문에서 먼저 설명. 응력·상전이를 깊게 다루는 부분을 읽을 때 관련 기초가 필요하면 선수학습으로 지정. |
| XRD·분광·단면 관찰의 상세 원리 | 기존 평가·분석 항목 | NCM 본문에서 무엇을 확인하는지 설명하고, 상세 측정·처리 방법은 연계학습으로 연결. |

선수학습에는 본문의 이해를 실제로 막는 항목만 넣는다. 심화 분석까지 한꺼번에 선행 조건으로 만들지 않는다. 같은 두 항목이 서로를 필수 선수학습으로 요구하면, 공통 기초를 분리하거나 한쪽의 설명 수준을 조절한다.

## 4. 언제 독립 소분류를 만들까?

다음 세 가지를 충족하는 개념은 별도 항목 후보로 둔다.

1. 여러 소재·공정·분석 문서에서 반복해서 사용한다.
2. 독립적인 학습 목표와 설명·예제·확인 문제를 만들 수 있다.
3. 다른 항목과 범위를 명확하게 구분할 수 있다.

특정 소재에서만 필요한 짧은 현상 설명은 소재 문서의 절로 둔다. 예를 들어 NCM의 특정 충전 구간에서 나타나는 c축 변화는 NCM의 현상이고, 비등방성 변형·응력의 일반 원리는 여러 소재에서 재사용하는 기초가 될 수 있다. 현재는 기존 “상전이·응력·균열” 안에서 설명을 먼저 발전시키고, 내용이 충분해지면 독립 분류 필요성을 검토한다.

새 WBS 번호를 즉시 늘리는 대신, 실제 작성 중 반복되고 길어지는 주제를 후보로 기록한다. 새 분류를 확정할 때 분류와 문서 연결을 함께 검토한다.

## 5. 파일 검토와 확정

파일 공유 → 함께 확인·수정 → 사용자가 확정 → GitHub 반영 순서로 진행한다. 새 학습문서는 먼저 검토용 파일로 제공한다. 사용자와 내용·구성·가독성을 확인하고 수정한 뒤, 사용자가 확정한 버전을 게시한다. 확정한 내용은 해당 항목의 Markdown과 목차에 반영한다. PDF는 별도 요청 시 최신 GitHub 내용을 바탕으로 채팅에서 제공하며 상위 합본은 만들지 않는다. 학습 상태는 문서 확정 여부와 별개로 기록한다.


사용자가 양식과 구체적인 대상 범위의 일괄 반영을 승인하면, 그 범위의 문서를 작성·검증하고 GitHub에 함께 반영한다. 이전에는 1.1 소재·재료 93개 항목을 일괄 작성했으나, 현재는 Li·Ni·Mn 외 자동 작성 본문을 삭제하고 함께 학습할 항목부터 하나씩 작성한다. 문서의 게시와 실제 학습 완료는 별개다.

## 6. 예제·근거의 선택과 갱신

- 작성·수정 시점의 최근 원 논문과 공식 자료를 확인한다. 현재 연구가 활발한 소재 사례를 우선하되, 설명하려는 원리에 적합해야 한다. NCM·LFP/LMFP·Na 전극은 현재의 예시 후보이며 영구 고정 목록은 아니다.
- 확인일·논문 시점·조성·전극·전해질·전위·온도 등 적용 조건을 남긴다. 특정 시료의 결과를 계열 전체의 성질로 확대하지 않는다.
- 이론 상한, 가정을 적은 교육용 계산, 실제 측정값을 구별한다. 활물질·복합분말·코팅·셀의 질량 기준과 전위의 기준 전극을 명시한다.
- 기본 이론에는 정립된 교재·정의·기초 원 논문도 사용한다. 최근 연구라는 이유만으로 필요한 기초 설명을 대체하지 않는다.
- 연구 흐름이 바뀌면 사례·근거·본문을 같이 갱신한다. 실제로 확인한 범위의 근거만 쓰고, 초록·공개 부분만 확인한 논문에서 상세 수치·절차를 추정하지 않는다.
- 독립 WBS 후보는 반복되는 개념이 충분히 자랐을 때 제안한다. 지금 분류를 임의로 늘리지 않는다.
