# 이차전지 WBS 앱: 국제·국내 표준 참조 지침

> 확인일: 2026-09-24
> 목적: 이차전지 아이디어·제품·재료·자료를 정리할 때 WBS 구조와 전극·셀 관련 표준의 적용 범위를 구분한다. 이 문서는 표준 원문의 대체 자료가 아니다.

## 1. WBS 구조와 지식 분류를 구분한다

| 구분 | 국제표준 | 국내표준 | 앱에서 참고할 점 |
| --- | --- | --- | --- |
| 작업 분류 체계 | [ISO 21511:2018](https://www.iso.org/standard/69702.html) — 프로젝트·프로그램의 WBS 지침 | [KS A ISO 21511](https://www.kssn.net/search/stddetail.do?itemNo=K001010149118) — 2024-09-05 제정, ISO 21511:2018과 일치(IDT) | 정의한 프로젝트 범위를 점차 작은 작업 요소로 나누고, 부모·자식 관계 및 각 요소의 설명을 관리한다. |
| 전지 용어 | [IEC 60050-482:2004](https://webstore.iec.ch/en/publication/215) — 일차·이차전지 용어 | [KS C IEC 60050-482](https://www.kssn.net/search/stddetail.do?itemNo=K001010141057) — 2022-12-13 개정 | 셀, 전지 등 용어를 일관되게 기록한다. |

ISO 21511은 **프로젝트 범위에 필요한 작업을 계층적으로 분해**하는 WBS를 다룬다. 부모 요소에 속한 작업을 자식 요소들이 빠짐없이 포괄하는 *100% 규칙*, 각 요소의 설명을 담는 *WBS 사전*, 진행 중 상세화하는 개념을 참고할 수 있다. ISO는 앱 화면 구성이나 데이터베이스 구현 방식을 지정하지 않는다. [ISO 정의·범위](https://www.iso.org/obp/ui?_escaped_fragment_=iso%3Astd%3Aiso%3A21511%3Aed-1%3Av1%3Aen)

**앱 설계 제안:** `양극 > LFP > 논문`처럼 주제로 자료를 모으는 트리는 *지식 분류*로, `LFP 양극 후보 평가 > 시료 준비 > 시험 결과`처럼 프로젝트 범위를 분해하는 트리는 *WBS*로 표시한다. 아이디어·제품·재료·문헌은 두 구조에 연결할 수 있게 한다. 주제 폴더만 만든 경우 ISO 21511에 따른 프로젝트 WBS라고 표시하지 않는다.

ISO의 [ISO/PRF 21511](https://www.iso.org/standard/87898.html)은 2026-09-24 현재 개정 초안의 승인 단계이며 아직 발행된 대체 표준이 아니다. 발행되면 이 문서의 판본과 KS 채택 여부를 다시 확인한다.

## 2. 전극을 다룰 때 우선 참조할 시험 표준

아래 IEC `TS`는 **기술시방서(Technical Specification)**이다. 목록의 상당수는 **나노물질 또는 나노 활용 전극**에 한정된다. 일반적인 모든 양극재·음극재, 모든 코팅 공정에 그대로 적용된다고 간주하지 않는다. `IDT`는 국내 KS가 표시된 IEC 판본과 *일치 채택*되었다는 KSSN의 표기다. IEC 판본 연도와 KS의 제·개정 연도는 별도로 기록한다.

| 평가 대상 | 국제 기술시방서 | 국내 KS | 적용 범위와 기록할 항목 |
| --- | --- | --- | --- |
| 양극 나노물질의 전기화학 특성 | [IEC TS 62607-4-1:2015](https://webstore.iec.ch/en/publication/23122) | [KS C IEC TS 62607-4-1](https://kssn.net/search/stddetail.do?itemNo=K001010151278), 2026-03-13 개정 이력, IEC 2015판 IDT | 2전극 측정법. LFP(리튬인산철) 같은 양극 나노물질의 평가 기록에 연결. |
| 양극 나노물질 분말의 밀도 | [IEC TS 62607-4-2:2016](https://webstore.iec.ch/en/publication/26101) | [KS C IEC TS 62607-4-2](https://www.kssn.net/search/stddetail.do?itemNo=K001010132544), 2021-05-21 제정, IDT | 분말 시료의 밀도 측정. 전극 코팅층의 밀도와 혼동하지 않는다. |
| 전극 물질의 접촉·코팅층 비저항 | [IEC TS 62607-4-3:2015](https://webstore.iec.ch/en/publication/23121) | [KS C IEC TS 62607-4-3](https://www.kssn.net/search/stddetail.do?itemNo=K001010142987), 2023-05-12 제정, IDT | 나노 활용 전극 물질의 접촉 및 코팅층 비저항 시험. 제조 조건과 측정 결과를 구분해 연결. |
| 양극 나노물질의 전기화학 특성 | [IEC TS 62607-4-5:2017](https://webstore.iec.ch/en/publication/27061) | [KS C IEC TS 62607-4-5](https://www.kssn.net/search/stddetail.do?itemNo=K001010157128), 2026-03-13 개정, IEC 2017판 IDT | 3전극 측정법. 전극별 성능·열화 기여를 살피는 자료에 연결할 수 있으며 적용 대상을 기록한다. |
| 음극 나노물질의 자성 불순물 | [IEC TS 62607-4-7:2018](https://webstore.iec.ch/en/publication/33479) | [KS C IEC TS 62607-4-7](https://www.kssn.net/search/stddetail.do?itemNo=K001010132545), 2021-05-21 제정, IDT | ICP-OES(유도결합 플라스마 광학 방출 분광법)에 의한 자성 불순물 측정. |

### 함께 참고할 전극 자료

- [IEC TS 62607-4-6:2018](https://webstore.iec.ch/en/publication/33796): 나노 전극 물질의 탄소 함량을 적외선 흡수법으로 평가한다. 이번 목록에서 대응 KS 판본은 확인하지 않았으므로 국내 표준번호를 임의로 붙이지 않는다.
- [IEC TS 62607-4-8:2020](https://webstore.iec.ch/en/publication/62187): 전극 나노물질의 수분 함량을 칼피셔 전량 적정법(Karl Fischer, 화학 반응을 이용해 물을 정량하는 방법)으로 측정한다. 시료와 시약 간 반응에 따른 적용 제외 조건이 있으므로 시료 적합성을 확인한다. 대응 KS 번호는 이번 목록에서 확인하지 않았다.
- [KS M 1077(2023 확인)](https://www.kssn.net/search/stddetail.do?itemNo=K001010143625): 국문 표제·적용 범위에는 **양극 활물질**의 납·카드뮴 정량이라고 기재돼 있지만 같은 목록의 영문 표제에는 *anode*라고 기재돼 있다. 원문 확인 전에는 앱이 이 항목을 양극/음극으로 자동 분류하지 않고 `표제 확인 필요`로 표시한다.

## 4. 앱에 넣을 기록 규칙 (설계 제안)

### 저장 형식 설계에 참고할 국제·국내 표준

아래 표준은 **분류·기록·표기 원칙**을 제공한다. 특정 JSON 키, CSV 열, 데이터베이스 종류 또는 폴더명을 지정하지 않는다. 앱의 파일 형식과 필드명은 이 원칙을 참고해 별도로 설계한다.

| 설계 대상 | 국제표준 | 국내표준 | 앱에 반영할 원칙 |
| --- | --- | --- | --- |
| 프로젝트 작업의 분해와 연결 | [ISO 21511:2018](https://www.iso.org/standard/69702.html) | [KS A ISO 21511](https://www.kssn.net/search/stddetail.do?itemNo=K001010149118) | 프로젝트별 작업 요소에 고유 ID·부모 ID·범위·산출물을 둔다. `전극 > 양극 > 도공` 같은 주제 분류와 구별한다. |
| 분석 결과와 원자료의 기록 관리 | [ISO 15489-1:2016](https://www.iso.org/standard/62542.html) | [KS X ISO 15489-1](https://www.kssn.net/search/stddetail.do?itemNo=K001010132240) | 결과·원자료·작성 주체·생성 시점·변경 이력을 서로 연결해 해석 가능한 기록으로 보관한다. |
| 기록 메타데이터(기록의 맥락을 설명하는 정보) | [ISO 23081-1:2017](https://www.iso.org/standard/73172.html) | [KS X ISO 23081-1](https://www.kssn.net/search/stddetail.do?itemNo=K001010153502) | 출처, 생성 주체, 관련 작업, 관계, 이력 같은 메타데이터를 정의한다. 이 열거는 앱의 설계 제안이며 표준이 강제하는 필드 목록은 아니다. |
| 작성·측정 날짜의 표기 | [ISO 8601-1:2019](https://www.iso.org/standard/70907.html) | 국내 대응 표준 확인 전 | 저장 시 날짜·시간과 시간대를 일관되게 기록한다. 예: `2026-09-27T17:00:00+09:00`. |
| 수치의 물리량과 단위 표기 | [ISO 80000-1:2022](https://www.iso.org/standard/76921.html) | 국내 대응 표준 확인 전 | 전극 로딩량·두께·용량 등은 수치와 단위를 함께 기록하고 변환 기준을 명시한다. |

**전극 분석 기록의 예시:** 원본 CSV를 보존하고, 별도 기록에 `id`, `title`, `knowledge_category_id`, `wbs_task_ids`, `source_files`, `analysis_script`, `result_files`, `created_at`, `author`, `review_status`, `measurements`(값·단위), `standard_refs`(번호·판본·적용 판단)를 둔다. 하나의 분석이 여러 WBS 작업과 연결될 수 있으므로 `wbs_task_ids`는 목록으로 둔다. 이는 **앱 자체의 데이터 스키마 설계안**이며 국제·국내 표준의 공식 저장 포맷이라고 표시하지 않는다.

예를 들어 `전극 > 양극 > 도공`은 탐색용 *지식 분류*이고 `LFP 양극 후보 평가 > 도공 조건 비교`는 프로젝트의 *WBS 작업*이다. 같은 분석 기록을 두 항목에 각각 연결할 수 있다. 전극 시험 표준은 측정 대상과 방법이 실제 적용 범위에 들어맞을 때만 `standard_refs`로 연결하며, 표준 번호의 연결만으로 시험 적합성을 주장하지 않는다.

1. **WBS 작업 노드**에는 고유 ID, 부모 ID, 프로젝트 범위, 기대 산출물, 작업 설명, 연결된 지식 항목을 둔다. 범위가 바뀌면 하위 작업이 상위 범위를 계속 포괄하는지 검토한다.
2. **지식 항목**에는 아이디어/제품/재료/자료 유형, 양극·음극 구분, 소재계, 제조 단계, 원문 출처, 핵심 주장과 근거를 둔다. 하나의 자료를 여러 작업에 연결할 수 있게 한다.
3. **표준 참조**에는 표준번호, 판본 연도, 국제 문서 유형(IS·TS), 국내 KS 채택 여부, 적용 대상(분말·전극층·셀·전지·팩/시스템), 평가 항목, 대응 KS, 공식 링크, 최종 확인일을 저장한다.
4. **적용 판단**은 `관련 가능` → `적용 범위 확인` → `시험 근거 연결`의 상태로 구분한다. 표준 번호를 자료에 붙였다는 이유만으로 적합성이나 인증을 주장하지 않는다.

### 전극 중심 연결 예시

| 앱의 위치 | 저장할 내용 | 연결할 수 있는 표준 |
| --- | --- | --- |
| 지식 분류 `전극 > 양극 > LFP` | 아이디어, 소재 특성, 논문·제품 자료 | 관련 표준의 적용 범위를 확인한 뒤 62607-4-1·4-2·4-5 |
| WBS `LFP 양극 후보 평가 > 전극 시료·측정 결과` | 시료와 제조 조건, 접촉·코팅층 비저항 결과 | 62607-4-3, 나노 활용 전극에 해당하는 경우 |
| WBS `LFP 양극 후보 평가 > EV 셀 검증 결과` | 완성 셀의 성능·수명, 시험 조건과 원자료 | EV 구동용 셀에 해당하는 경우 62660-1 |

## 5. 유지 관리

- ISO 21511의 후속판이 발행되면 국제판 상태를 확인하고, KS A ISO 21511의 채택·개정 여부를 **별도로** 확인한다.
- 표준을 앱에 추가할 때는 [ISO](https://www.iso.org/), [IEC](https://webstore.iec.ch/), [한국표준정보망 KSSN](https://www.kssn.net/) 등의 공식 표준 목록에서 번호·판본·적용 범위·개정 이력을 확인한다.
- 시험 조건·허용 기준·합격 판정은 요약만 보고 확정하지 않는다. 실제 시험에는 해당 표준 원문과 최신 판본을 확인한다.
