# 양극재 분류와 구성 원소의 연결

> 2026-10-02 | 지식 탐색 구조의 제안

LFP·LMFP·NCM·LMO를 양극재의 구조·조성 계열별로 분류하고, 각 소재의 설명에서 구성 원소 문서를 연결한다. 재료 종류와 구성 원소는 다른 관계다.

| 탐색 경로 | 소재 | 대표 화학식 | 구성 원소 |
| --- | --- | --- | --- |
| 설계 → 소재·재료 → 활물질 → 양극재 → 인산염계 | LFP | LiFePO₄ | Li·Fe·P·O |
| 같은 인산염계 | LMFP | LiMnₓFe₁₋ₓPO₄, 0 < x < 1 | Li·Mn·Fe·P·O |
| 설계 → 소재·재료 → 활물질 → 양극재 → 층상 산화물 | NCM | LiNiₓCoᵧMn_zO₂, 대표적으로 x+y+z=1 | Li·Ni·Co·Mn·O |
| 같은 층상 산화물 | NCA | LiNiₓCoᵧAl_zO₂, 대표적으로 x+y+z=1 | Li·Ni·Co·Al·O |
| 같은 층상 산화물 | LCO | LiCoO₂ | Li·Co·O |
| 설계 → 소재·재료 → 활물질 → 양극재 → 스피넬계 | LMO | LiMn₂O₄ | Li·Mn·O |

위 화학식은 대표 조성을 표현한다. 실제 시료는 조성비, Li 비화학양론, 도핑, 코팅 등을 별도 기록한다. 충·방전 상태에 따라 Li 함량과 산화상태가 달라질 수 있다.

## 소재를 눌렀을 때

정의·조성 → 결정구조 → 원소별 역할 → 충·방전 반응 → 특성·측정조건 → 전극 설계·제조 연결 → 열화·분석·해결 변수 → 질문 → 출처를 보여주는 형태로 설계한다.

`LFP → 구성 원소 → Li`를 누르면 [Li 공통 상세](../Knowledge/materials/Li.md)를 연다. LFP, NCM, 전해질의 Li 링크는 같은 문서 ID `element.li`를 가리킨다. Li가 LFP의 하위 재료 종류인 것처럼 표현하지 않는다.

## 앱의 관계 데이터

- `parent_id`: 소재 종류의 탐색 계층.
- `contains_element_ids`: 화학적 구성 원소 관계.
- `related_node_ids`: 열화·분석·공정 등 관련 지식.

화학적 구성과 부모 계층을 구분하면 하나의 Li 문서를 여러 소재에서 열 수 있고, 설명 개정도 한 번에 적용된다. 현재는 분류 데이터와 문서 연결 설계이며 클릭 화면은 후속 구현이다.
