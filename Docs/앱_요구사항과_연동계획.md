# 이차전지 지식·WBS 앱 요구사항과 연동 계획

> 정리일: 2026-10-02 | 저장소: cruvty2-dot/battery-study

## 목적과 확정된 요구

이차전지의 설계·공정 자료를 작은 주제로 탐색하고, 재료의 기본 특성부터 전극·셀 성능과 실험 결과까지 연결한다. GPT/Work에서 요구를 정리하고 GitHub에서 문서·코드·변경 이력을 관리하며, Hermes와 작업봇은 분석 실행을 맡는 구조를 목표로 한다.

- 이차전지 아래의 최상위 지식 축은 설계와 공정이다.
- 각 분류는 세분화하고 바뀌지 않는 ID를 부여한다.
- Li 같은 공통 재료의 문서는 하나를 만들고 여러 위치에서 연결한다.
- 첨부 자료는 수정·추가·삭제가 가능한 참고자료로 사용한다.
- PDF는 사용자가 선택한 주제별 파일로 만든다. 충분한 원문은 추출하고 부족하거나 오해하기 쉬운 내용은 보완한다.
- 분석 결과에는 원자료·코드·그래프·조건·단위·출처·작성일·검토 상태를 연결한다.
- 국제·국내 표준은 범위와 판본을 확인해 설계 원칙 또는 시험 참조로 사용한다. 자체 JSON이 표준 공식 포맷이라고 표시하지 않는다.

## 화면 제안

왼쪽은 설계/공정의 지식 트리, 오른쪽은 선택한 항목의 설명과 연결 자료다. 프로젝트 작업 WBS는 별도 화면 또는 탭으로 둔다.

| 상세 화면 | 표시할 내용 |
| --- | --- |
| 기본 설명 | 정의·물성·조건·단위 |
| 배터리 역할 | 구성·충방전 반응·설계 변수 |
| 공정 연결 | 원료·혼합·도공·건조·압연·조립 등 |
| 평가·열화 | 관찰·가설·분석법·확인 범위 |
| 자료 | 주제 PDF·원본 파일명과 쪽수·논문·공식 자료 |
| 분석 기록 | 요약·그래프·입력·코드·실행 환경·검토 상태 |
| 아이디어·질문 | 가설·근거·확인할 작업·결과 |
| 프로젝트 작업 | 관련 WBS 작업과 산출물 |

## 연결 흐름 제안

1. GPT/Work에서 작업 요청을 만들고 입력 파일·분류 ID·기대 산출물을 명시한다.
2. GitHub의 작업 요청 파일 또는 Issue를 실행자가 읽는다.
3. Windows PC의 Hermes가 역할별 작업 지침과 파일·터미널 도구를 이용해 Python 등의 분석을 실행한다.
4. 결과 메타데이터가 분류·단위·파일 존재·개인정보/공개 범위를 검사한 뒤 브랜치에 저장된다.
5. 검토 후 확정한 결과만 앱의 기본 목록에 표시한다. 검토 대기 자료는 상태를 드러내어 별도로 열람한다.

Hermes의 공식 문서는 파일·터미널·코드 실행 도구와 예약 도구를 안내한다. 연결과 자동 실행에는 실제 설치, 모델, 도구 권한, Git 인증과 실행 환경이 필요하다. 여기서 정의하는 전극공정·설계 작업봇은 프로젝트의 역할 설계이며 설치가 완료된 봇 목록을 뜻하지 않는다.

| 역할 | 예시 작업 | 출력 |
| --- | --- | --- |
| 전극공정 분석 | 도공 조건·면밀도·두께·불량 변동 비교 | 표·그래프·편차·가설·검증할 조건 |
| 전극설계 계산 | 로딩량·활물질비·비용량·N/P 비교 | 계산식·단위·입력 기준·설계 비교 |
| 평가 데이터 해석 | 충방전·EIS·기기분석 전처리·피팅 | 코드·모델 가정·잔차·해석 범위 |
| 자료 분류 | 문헌을 지식 항목·프로젝트 작업에 연결 | 출처·근거·분류 후보·검토 상태 |

## 저장·검토 동작

분류가 확실한 결과는 해당 ID와 연결하고, 모호하면 분류 후보 목록과 이유를 남긴다. 중복 실행은 `request_id`와 입력·코드 해시로 식별하도록 구현한다. 실패한 실행은 로그와 상태를 남기고 완료 결과를 덮어쓰지 않는다. 실행자는 main 직접 덮어쓰기보다 작업 브랜치와 PR을 사용하도록 설정하는 것을 제안한다.

## 현재 완료 범위와 다음 구현

현재 산출물은 요구사항·분류 데이터·저장 규칙·주제별 지식 문서·참고 PDF·Li 상세 예시다. 클릭 가능한 웹앱, Hermes 설치·연결, GitHub 작업 감시, 자동 분석·저장은 구현되지 않았다.

다음 구현은 (1) JSON과 Markdown을 읽는 트리·상세 화면, (2) PDF와 관련 문서 열기·검색, (3) 분석 기록 표시, (4) 검토 상태 전환, (5) 실제 PC 실행자 연결의 순서로 진행한다.
