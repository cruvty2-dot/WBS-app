## 분류와 검증 방향

| 원문 질문·아이디어 | 대표 분류 | 관련 분류 | 확인할 내용 |
| --- | --- | --- | --- |
| EIS로 조기 문제 식별·관리·회수 | 공정 → 재사용·재활용 → 잔존성능·재사용 진단 | 설계 → 평가 → EIS | 온도·SOC·이력 영향과 진단 지표 검증; 안전검사·이력과 조합 |
| 어느 부분을 살리고 교체할 것인가 | 공정 → 재사용·재활용 → 재사용·재제조 | 셀·시스템 설계 | 셀·모듈·팩 수준과 고장 형태별 판정 기준 |
| 활물질만 회수할 것인가 | 공정 → 재사용·재활용 → 분해·전처리 | 직접 재활용·습식·건식 제련 | 재사용과 소재 재활용 경로의 구분, 회수 대상·경제성·품질 |
| 활물질 문제를 어떻게 식별할 것인가 | 설계 → 평가 → 열화·고장 분석 | 기기분석·전기화학 | LAM·LLI·저항 증가 구분과 교차 검증 |
| 문제 부분만 소생시킬 수 있는가 | 공정 → 재사용·재활용 → 직접 재활용·재리튬화 | 소재 구조·Li | 소재계·열화 형태·불순물별 재생 가능성과 성능 검증 |
| 처음부터 재사용을 고려할 수 있는가 | 설계 → 셀·시스템 → 분해·재사용을 고려한 설계 | 공정 → 회수·이력 | 분해성·이력·진단 접근성과 성능·비용의 상충 |
| 반도체에서는 재사용을 하는가 | 비교 산업 조사 질문 | 순환 설계 | 원문에서 질문만 제시됨; 비교 가능한 공정·대상과 출처 추가 필요 |

EIS를 사용하면 안전사고를 막거나 모든 결함을 찾아낼 수 있다는 검증된 결론으로 바꾸지 않았다. 각 아이디어는 목표, 원인 가설, 근거, 검증 방법, 판정 지표를 작성한 뒤 프로젝트 WBS로 전환한다.
