# Li: 원소·리튬 이온·금속 음극

> ID: element.li | 개정일: 2026-10-02 | 대표 위치: 설계 → 소재·재료 → 소재 특성·전공 기초 → 원소·이온

Li는 원소 리튬의 기호다. 배터리 자료에서는 **원소**, **Li⁺(리튬 이온)**, **금속 리튬 음극**을 구분해야 한다. NCM·LFP·전해질·재활용 항목에서 같은 문서를 연결한다.

## 1. 기본 물성

| 항목 | 값·설명 | 적용 대상 |
| --- | --- | --- |
| 원자번호 | 3 | 리튬 원소 |
| 상대 원자질량 | 약 6.94 | 대표 원자량; 동위원소 조성에 따라 달라질 수 있음 |
| 전자배치 | [He] 2s¹ | 중성 원자 |
| 밀도 | 0.534 g/cm³ | 금속 Li, 실온 기준 |
| 녹는점 | 180.50 °C | 금속 Li |
| 흔한 산화수 | +1 | 화합물·이온에서의 대표 상태 |

위 값은 RSC의 원소 자료에서 확인했다. 금속의 밀도·녹는점을 LiFePO₄·LiPF₆·전해액의 물성으로 사용하지 않는다. 물에 대한 높은 반응성도 금속 Li의 특성으로 기록한다.

## 2. 배터리에서의 역할

| 위치 | Li를 읽는 방법 | 함께 연결할 내용 |
| --- | --- | --- |
| LFP·NCM 등 양극 | 결정구조에 포함된 Li의 탈리·삽입과 전하 보상 | 조성·산화환원·상변화·사용 전압창 |
| 전해질 | 이동 가능한 Li⁺와 용매·음이온의 상호작용 | 염·용매·첨가제·이온전도 |
| 흑연 음극 | Li가 탄소 층 사이에 저장되는 삽입 반응 | 흑연·SEI·급속충전 |
| 금속 Li 음극 | Li⁺ + e⁻ ⇄ Li의 도금·박리 | 계면·형상·효율·수명 |
| 열화 | 순환 가능한 Li가 부반응·고립으로 줄어들 수 있음 | LLI·석출·고립·리튬 재고 |
| 소재 재활용 | 회수 원소·재리튬화 입력으로 관리 | 물질수지·순도·구조·재생 성능 |

전자는 외부회로를, 이온은 전해질 경로를 이동한다. 충·방전은 전극 반응과 두 경로가 연결되는 과정이다. 모든 이차전지가 Li를 사용하는 것은 아니므로 데이터에는 Li계·Na계 등 화학계를 따로 기록한다.

## 3. 금속 음극의 용량·전위

금속 Li의 이론 비용량은 약 **3,860 mAh/g**이다. 이는 금속 Li 질량 기준이며 셀 전체의 용량·에너지밀도가 아니다. 계산식은 `q = nF/(3.6M)`이고, Li에서는 전자 수 n=1, 몰질량 M≈6.94 g/mol을 쓴다. 전극의 실제 가역용량·수명은 계면과 시험조건의 영향을 받는다.

Li/Li⁺ 기준의 0 V는 해당 기준전극에 대해 정의한 값이다. 문헌에서 약 -3.04 V가 나오면 표준 수소전극(SHE) 기준인지 확인한다. 서로 다른 전위 기준을 그대로 빼서 셀 전압을 계산하지 않는다.

## 4. 열화와 검증

금속 Li의 반복 도금·박리에서는 불균일 형상, 계면 반응, 비가역 Li 손실이 중요하다. 수지상 구조만이 모든 실패의 원인은 아니다. 동결·단면 관찰 연구가 소개한 반응 생성물과 분리막 손상도 특정 조건의 원인 사례다.

| 관찰·분석 | 직접 확인하는 정보 | 해석의 한계 |
| --- | --- | --- |
| 충·방전 용량·효율 | 정한 조건에서 들어간·나온 전하량 | 손실 위치와 화학종을 단독 확정하지 못함 |
| EIS | 주파수별 임피던스 응답 | 특정 열화·안전 상태의 단독 판정법이 아님 |
| XRD | 결정상·격자·구조 변화 | 전체 Li 재고를 곧바로 정량하지 못함 |
| ICP 분석 | 전처리한 용액의 원소 농도 | 검량·희석·회수율을 확인해야 하며 저장 가능 Li와 다름 |
| 표면·단면 분석 | 관찰 위치의 형태·화학 상태 | 위치·전처리·공기노출의 영향을 기록해야 함 |
