## 보완 설명

### EIS 해석의 범위

EIS(Electrochemical Impedance Spectroscopy, 교류 신호에 대한 응답을 주파수별로 측정하는 방법)는 여러 과정이 겹친 응답이다. 반원의 크기 하나를 특정 열화나 재사용 안전성의 확정 증거로 쓰지 않는다.

### 조건과 모델

SOC, 온도, 휴지 시간, 신호 크기, 주파수 범위, 전극 구성을 기록한다. 등가회로 피팅은 모델 선택·초기값·잔차·파라미터 신뢰범위와 함께 보관한다.

### 기기분석의 한계

SEM 형상, EDS 원소 신호, XPS 표면 화학상태, ICP 용액 원소 농도는 같은 관찰량이 아니다. Li 검출·정량 가능성은 기기 사양과 전처리·검량을 확인한다. 원소 분포 그림 하나로 저장 가능한 Li 양을 확정하지 않는다.

### Python 활용

CSV의 원본을 유지하고 단위·결측·중복·시료 ID를 먼저 검사한다. 전처리와 피팅 코드를 저장하고 실측·계산·모델 예측 결과를 서로 구분한다. 원본의 직접 경험 표시는 참고자료 저자의 기록이며 앱 전체 사용자의 수행 이력으로 자동 전환하지 않는다.

## 확인할 질문·실습

같은 데이터로 관찰, 모델 가정, 원인 후보, 확인 실험을 네 칸에 작성한다.

## 참고자료 사용 범위

원본의 표·그래프·질문을 맥락과 함께 추출하고 보완 설명을 앞에 추가했다. 원본의 쪽수·절 번호와 이전 다른 절 참조는 [쪽수 대응표](../../Docs/원본_자료_배치표.md)로 연결한다. 원본 전체의 독립적 사실검증이나 최신 규격 적합성 검토를 완료했다는 뜻은 아니다.
